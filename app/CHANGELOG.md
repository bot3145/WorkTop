# 变更记录

本文件记录用户可见的变更。版本号遵循 SemVer。

## [3.1.0] 2026-10-31

### 变更
- **项目更名 WorkTop**：与 Lite 版合并为同一产品（`WorkTop/app` + `WorkTop/lite`），productName/安装包/托盘均改为 WorkTop。
- **桌宠模块整体移除**：webm 素材、素材扫描、行为状态机、`petasset://` 协议、桌宠设置面板全部删除——安装包从 54 MB 降到 **2.7 MB**，且不再含任何 CC BY-NC-SA 第三方素材（纯 MIT 可商用）。
- **新增原创吉祥物「托托」**：手绘小圆形卡通形象（果冻团子：Q 弹压扁拉伸 / 眨眼 / 嫩芽摇摆 / 漂浮），可拖动；拖到屏幕边缘自动**折叠一半**、点击展开；未折叠显示**当天待办数量**角标（与待办页「今天」同口径：due=今天且未完成）；**点击弹出环形菜单**（参考 x-hub FloatingBallWindow：待办/速记/AI/设置 52px 烟玻璃圆钮绕人物 360° 均分、双层轨道装饰环、螺旋扫出动画、失焦优雅收起；**双击人物唤起工作台主窗**）；托盘提供显示/隐藏。
- **桌面卡片编排器迁移**：原由桌宠窗口兼任的卡片窗口同步逻辑移入主窗口（`App.vue` 的 `syncCards`），桌面模式下自动按配置创建/归位 9 种卡片；卡片开关与字号倍率新增到「设置 → 桌面卡片」标签页。
- **弧形菜单跟随星球**：菜单纵向对齐星球中心（锚点经 URL 传给菜单窗，弧形圆心始终贴着星球，即使被屏幕边缘夹住）；折叠在哪侧就朝另一侧弹；弧半径 86→72、菜单窗 240→180，快捷入口更紧凑。
- **修复卡片勾选不显示**：配置广播事件名 `pwb-pet-config` → `pwb-desktop-config` 与监听端对齐（改名漏改导致的断链）；卡片 × 关闭现在也广播，设置页开关状态不再脱节。
- 配置键迁移：`设置.json` 的 `pet` 键自动迁移为 `desktop`（卡片布局/开关/字号原样保留）。

## [3.2.0] 2026-11-10

### 变更
- **开机自动启动**：「设置 → 桌面卡片」新增开关（`tauri-plugin-autostart`，写 Windows 登录项）。开启后登录即在后台静默启动，带 `--autostart` 参数；桌面壳模式下直接进桌面、不弹工作台主窗（也不会闪一下）。关闭即从登录项移除。
- **吉祥物菜单「秒开」**：弧形菜单窗改为**启动时预热、常驻复用**——原来每次点击都要新建一个 WebView2 窗口并加载整页前端（那才是延迟的大头），现在点一下只做 `set_position` + `show`，收起只是 `hide` 不销毁；同时扫出动画从 0.34s/35ms 递减到 0.2s/16ms、收起 0.28s→0.16s、关窗等待 430ms→240ms，弹出到全部就位约 **0.3s**。窗口复用后「打开」改由 Rust 发 `mascot-menu:show` 事件驱动重播动画（并保留可见性兜底，预热失败现建窗也能正常播）。
- **吉祥物菜单入口顺序调整**：截图上移一位、设置移到底部（正下方），即 待办 → 速记 → AI → 截图 → 设置。
- **应用模块改为「启动台」样式**：顶部居中搜索条（右侧显示应用总数）、右上角**无底板的大号时钟**（11px 日期小字 + 28px 细体时间，直接浮在极光背景上，窄窗口自动降到 22/17px 并收掉日期；**原右上角齿轮按钮已去掉**，目录设置改在底部 dock）、分类胶囊（全部 / LNK / URL / EXE / APP，按实际扩展名动态出现）、圆角图标网格（悬停上浮、置顶角标）、分页圆点（滚轮翻页）与底部玻璃 dock（打开目录 / 刷新 / 设置目录 / 取消目录 + 当前目录）。**置顶单独成区**：紧贴搜索条下方、分类胶囊上方，用略小的图标排成 **1–2 排**并以细分隔线收尾（窗口够高才给 2 排，矮窗自动只占 1 排；超出排数的置顶项回落到主网格首部，仍带星标，不丢数据）。**数据与功能一字未改**：仍是同一个应用目录、同一份置顶列表，启动 / 置顶 / 搜索 / 目录设置全部沿用原有命令；跟随明暗主题（暗色为极光深色版）。
- **启动台覆盖层同步视觉**：模块入口改成极光玻璃面板 + 4×2 图标网格，补齐 8 个模块的渐变配色，悬停上浮；打开板块与 Esc 关闭行为不变。
- **APP 图标按吉祥物重制**：以桌面「能量球」为原型新绘 1024×1024 母版（珠光玻璃球、双眼神态、腮红微笑、发光天线、虚线轨道与卫星、柔光渐变卡底与接触阴影），经 Edge 无头渲染后用 `tauri icon` 生成全套 ico / png / icns。母版与源图保留在 `app/design/`（`app-icon.svg` + `app-icon-1024.png`），改图标只需改 SVG 再重新渲染。

### 新增
- **在线更新（GitHub Releases）**：接入 `tauri-plugin-updater`，「设置 → 关于 → 软件更新」可一键检查更新（读 `https://github.com/bot3145/WorkTop/releases/latest/download/latest.json`），有新版显示版本号与更新说明，可下载（带进度条）、装完提示「立即重启生效」。更新包走 **minisign 签名校验**（公钥已写入 `tauri.conf.json`，私钥在打包机上，绝不入库）。同时补了 `.github/workflows/release.yml`：推 `v*` tag 即自动编译 NSIS 安装包 + 生成 `latest.json` 并上传 Release。`build.rs` 之外无需额外配置，开发模式下检查会明确报错（需打包版本才会真正比对版本）。
- **模块锁（口令门禁）**：给「密钥文档 / 资产 / 速记」加可选的**口令门禁**——「设置 → 安全」里设一次口令、勾选要保护的模块；这些模块打开时先显示锁屏，输对口令才加载内容，其它已打开的窗口同时收回。**文件始终保持 Markdown 明文**（Obsidian 可直接编辑、AI 工具可直接读写），口令只拦界面访问；退出程序自动全部重新上锁，「立即全部上锁」可随时手动收。口令经 scrypt 派生、只存 HMAC 校验值于 `设置.json`，与凭据库主口令互不影响。
- **随启动自动拉起截图组件**：应用启动时后台静默拉起 AirSnip 常驻托盘（不弹窗、不转发热键），之后随时按 F1 截图；AirSnip 带 UAC 提权要求（CreateProcess 报 740），自动经 explorer 转发处理。`snip_ensure` 命令也可手动触发。
- **功能窗口标题栏加最大化按钮**：最小化与关闭之间新增「最大化/还原」，占满工作区、还原后回原位（Windows 系统级最大化）；最大化时窗体去圆角贴合屏幕边缘。全部 8 种功能窗口生效。
- **合并安装开源截图工具 AirSnip**：[AirSnip 轻截](https://github.com/bd-dxg/airsnip) v0.7.0（GPL-3.0 独立程序，Rust 单文件 1.2MB）随安装包分发——`npm run airsnip:fetch` 构建前拉取到 `src-tauri/sidecar/airsnip/`（不进 git），NSIS 打包带上；`snip_capture` 统一入口（桌宠菜单「截图」/ Dock 右键 / 桌面右键）优先用随包副本：不在跑则拉起常驻，然后转发其截图热键 **F1**。键盘党直接按 AirSnip 自带的 F1 即可（其设置内可改键）——WorkTop 不注册全局热键，不占用系统「全选」。未找到副本时回落自带 PowerShell 拖选截图。GPL 以聚合分发保留双方许可（见 THIRD_PARTY_NOTICES），不想带就删 sidecar 目录构建纯 MIT 包。
- **桌宠菜单 5 入口改左侧扇形**：吉祥物点击菜单从 4 钮 360° 环形改为 5 钮**左侧半弧扇形**（12 点 → 9 点 → 6 点方向 45° 等分）：待办在正上方，依次速记/AI/设置/**截图**（新入口，调 `snip_capture`）；按钮缩小为 40px、轨道半径 72、新增单层轨道虚线环、扇形扫出动画；菜单窗 300×260、锚点（形象）在窗右侧；样式沿用 2026-11-02 定稿（浅色磨砂玻璃、主题色淡着色）。
- Dock 右键「截图并复制」、工作台桌面右键「截图」统一走 `snip_capture`（桌面右键此前漏了处理分支，点击无反应，一并修复）。

### 修复
- **换图标后任务栏还是旧图标**：图标是编译期嵌进 exe 的，`tauri-build` 默认不把 `icons/` 当依赖，改完图标只重启不重链接，看起来像没生效。`build.rs` 里补了 `cargo:rerun-if-changed=icons`，之后换图标保存即触发重新链接；本次已重新编译，新图标（含 16/24/32/48/64/256 六档）已确认写入 exe。
- **Dock 图标拖动排序**：按住图标拖动（超过 8px 判定为拖动，否则仍是点击启动/最小化），邻居图标实时平移让位，松手即固化新顺序（写入配置并即时重算 Dock 几何）。处于自动推荐模式时首次拖动自动固化为固定列表；横/竖向 Dock 均支持；拖动期间不触发自动隐藏收起，拖完不会误启动应用。

### 修复
- **修复：速记点「保存」毫无反应**。根因是两套索引错位：卡片列表把首个 `##` 之前的前导内容（`# 速记` 文件头）计为第 0 段，而按原文回写的小节区间没算它——新建卡后点保存取不到对应区间，直接静默返回；删除卡片同样错位（会删掉下一张卡的内容）。现在回写区间与前导段对齐；区间取不到时明确提示（内容保留在编辑框不丢）；文件头（`# ` 开头的第 0 段）禁止删除。

### 变更
- **Dock 启动提速**：点击图标不再经由 `explorer.exe`（原链路 = 起 explorer 进程 + ShellExecute + COM 解析快捷方式），改为**直接 CreateProcess 目标程序**——快捷方式的 target/参数/工作目录在扫描时就随图标一起预解析缓存，点击时零解析开销。需要 UAC 提权的程序自动回落系统打开（弹 UAC）；`.url` 仍走系统。
- **点击运行中的应用 = 最小化/恢复切换**：点 Dock 图标时，应用未运行则启动；运行中则最小化它的窗口（前台窗口优先）；已全部最小化则恢复最近活跃的那个并前置。多窗口应用不会出现"点一下最小化 A、再点又最小化 B"的错乱。
- **移除壁纸功能**：预设渐变、本地图片导入、壁纸设置标签、桌面右键「更换壁纸」、`wallpaper_import`/`wallpaper_list` 命令与 asset 协议放行全部删除（该功能此前有无法显示本地图片的缺陷，不再维护）。工作台桌面背景改用主题底色。
- **数据目录可修改并自动迁移**：设置 → 关于 → 「更改数据目录…」，选择空文件夹后确认，即把全部数据（待办/导航/速记/密钥/资产/AI 会话）完整迁移到新位置：校验（拒绝同目录/互相包含/非空目标）→ 拷贝 → 更新 `<app-data>/data-path.txt` → 原目录整体改名 `data-backup-<时间戳>` 保留（不删除，可回退）；迁移成功后运行时立即热切换，无需重启。迁回默认位置时自动删除标记回落默认解析。核心迁移逻辑带集成测试（正常迁移/各类拒绝场景）。
- **修复：「从已安装应用选择…」/「Dock 设置…」点了没反应**。原链路 emit 事件给工作台主窗口开设置——桌面壳模式下主窗隐藏，界面开在看不见的地方。现在直接打开**独立设置窗并直达「桌面 Dock」标签**（`pane_open` 新增 `tab` 参数，设置面板按 URL `?tab=` 定位初始标签）。
- **文件管理器进 Dock**：`explorer.exe` 没有开始菜单快捷方式，扫描永远抓不到——`dock_scan` 现在合成系统条目「文件管理器」（含真实图标提取），自动推荐保送前排；Dock 启动时发现缓存里没有它会自动补扫一次。
- **移除工作台主窗口的全部入口**：功能窗口标题栏不再有「工作台」按钮（绿色罗盘钮），Dock 右键菜单去掉「显示工作台」，吉祥物双击不再唤起主窗（单击弹环形菜单不变）；`main_show` 命令随之删除。桌面壳模式下工作台页面不可达（主窗保持隐藏，卡片编排不受影响）；设置里关闭「桌面壳模式」仍可回到传统工作台窗口（主窗即时显示，无需重启）。顺带清理：`pwb-open-app`/`pwb-ask-ai` 死监听器与重复的 `onResized` 注册。

### 变更
- **形象与环形菜单跟随工作台主题色**：新增共享调色板（经典蓝/樱花粉/护眼绿），能量球、天线、眼睛、轨道与 4 个按钮统一取色；设置里切换主题色时通过 `storage` 事件实时同步到悬浮窗，无需重启。球体为浅色珠光玻璃、按钮为浅色磨砂玻璃，主题色仅做 8%–35% 的淡着色，整体更轻。
- **吉祥物换成可爱圆形「能量球」**：圆润玻璃球身、两只表情眼 + 微笑 + 腮红、小天线、环形轨道卫星、圆内扫描光带与环绕光点，圆形轮廓无方形底板；
- **修复透明悬浮窗变成黑色方块**：`html.dock-win` 的 `color-scheme: dark` 会让 Chromium 把透明画布填黑；形象窗与菜单窗新增 `mascot-win` / `mascot-menu-win` 类并改为 `color-scheme: normal`，恢复真正透明。
- **展开菜单时形象严格居中**：展开时把形象窗口搬到菜单正中心（再贴边被夹也同心），收起后恢复展开前的吸附位置。
- **吉祥物与环形菜单完全照搬 x-hub 原始几何**：菜单窗 260×260、轨道半径 90px、4 个 52px 烟玻璃圆钮（图标 20px、文案 9px、原配色/阴影/扫出动画），形象恢复 x-hub 球体 48px 视觉档（窗口 52px）；角标与折叠提示同步恢复可读尺寸。
- **右键菜单只保留「退出程序」**：吉祥物右键原生菜单新增 `mascot_context_menu`（仅退出）；系统托盘右键同样精简为「退出程序」，移除显示/隐藏吉祥物与打开工作台项。

### 修复
- **资产卡右侧内容被裁**：网格列下限 230px 大于窄卡片内宽导致列溢出，改用 `minmax(min(230px,100%),1fr)` 夹住；名称可收缩、分组标签不换行。
- **各卡加了去重兜底**：应用（按文件）、导航（按 URL）、密钥（按名称+扩展名）重复项不再重复渲染。
- **修复：功能窗口关不掉**。`pane-*` 窗口漏登记 capabilities，导致窗口内所有 IPC（含 `close()`）被拒且错误被静默吞掉；补齐 7 个 pane 标签 + `allow-destroy`/`allow-set-title`，并把关闭改成三级兜底（`close` → `destroy` → Rust `pane_close`）；顺带支持 Esc 关闭、任务栏标题本地化。
- **修复：功能窗口标题栏拖不动**。`PaneWindow` 标题栏本就调 `startDragging()`，但 capabilities 漏授 `core:window:allow-start-dragging`，IPC 被拒且被 `.catch(()=>{})` 吞掉（与上面「关不掉」同源：无边框窗口依赖的窗口能力没登记全）；补权限即恢复拖动。
- **修复：桌宠带阴影**。去掉 `.pet-media` 的 `drop-shadow` 滤镜（完全透明）。
- **修复：Dock 置底时左右留白不均**。`placeByWorkArea` 只 `setPosition` 不 `setSize`，图标增减/横竖切换后窗口尺寸与内容不匹配；改为先 `setSize`，并按「Dock 本体」而非窗口算位置（窗口比本体大一圈用于悬停放大）；新增尺寸/位置变化的重测量；隐藏态改为按本体边缘滑出，热区手柄挪进本体。

### 修复
- **修复：替代任务栏时副屏鼠标失灵**。此前把副屏的 `Shell_SecondaryTrayWnd` 也一起隐藏，副屏那条位置成了"死区"（既没任务栏可点、也没窗口接管）。现在只隐藏主屏 `Shell_TrayWnd`，副屏任务栏保持原样；Dock 也只在主屏底部出现。

### 修复
- **「替代任务栏」改为默认关闭**（配置升 v3）：Dock 不再默认隐藏 Windows 任务栏，改为落在任务栏上方；v2 及更早的配置一次性迁移成关闭（之后在 Dock 设置里手动开启才生效）。Dock 挂载时若未开启替代，会主动 `taskbar_show()` 兜底，避免上次异常退出留下隐藏状态。

### 新增

### 修复（逐项走查发现）
- **待办新增会在文件里插空行**：`serializeTodos` 先追加新项再去尾部空行，导致新增项前多一行、且「加一条删一条」会累积空行。Rust/TS/pwb-lite 三处统一改成「先去尾部空行再追加」，并加回归测试。
- **速记「新建卡片」不生效**：写入新小节后下标取了 `entries.length`（多算一位），编辑框永不出现，文件里留下空小节。改为 `length - 1`。
- **导航链接点不开**：WebView 里 `window.open` 会被 Tauri 拦成新窗口或直接失效。新增 `open_external` 命令（只允许 http/https、拒绝控制字符、`CREATE_NO_WINDOW`），导航链接改走系统默认浏览器。
- **窗口「最大化 → 最小化 → 再打开」变成假最大化**：恢复时只把状态改回 `normal`，几何仍是最大化尺寸。新增 `prevState`，从最大化最小化的窗口唤起后回到最大化状态。
- 源码测试字符串里混入 4 个 NUL 字节（导致 grep/file 把源文件当二进制），改为 `\x00` 转义。
