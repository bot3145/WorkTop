# 安全策略

## 支持范围

| 版本 | 状态 |
|---|---|
| 3.x | 支持（当前开发线） |
| < 3.0 | 不支持 |

## 报告漏洞

**请不要在公开 issue 里贴漏洞细节。**

优先用 GitHub 的私密渠道：仓库 **Security → Report a vulnerability**（Private vulnerability reporting）。
如果该入口不可用，可以开一个只写"需要安全联系方式"的 issue，维护者会私下联系你。

请在报告里写清楚：受影响版本、复现步骤、影响（能读到什么 / 能执行什么）、你的环境（Windows/macOS 版本、是否开了凭据加密）。

一般 3 个工作日内回复；确认后会在修复版本发布时署名致谢（如果你愿意）。

## 威胁模型

Worktop 是**单用户、纯本地**的桌面应用。我们假设：

- 运行它的这台电脑是用户自己的，操作系统与 WebView2/WebKit 未被攻破；
- 数据目录里的 Markdown 可能被其他程序（同步盘、编辑器、恶意软件）读写；
- 从网络下载的**素材/图片**可能被构造过；
- 攻击者不能直接改 Worktop 的二进制（否则超出本项目的防护范围）。

在这个模型下需要守住的资产：

1. `凭据.md` 里的密码 / 私钥 / Token；
2. 主口令与系统钥匙串中的条目；
3. 用户数据文件不被越权读写、不被伪造内容注入。

## 已实施的防护

- **凭据加密**：主口令 → `scrypt(N=2^15, r=8, p=1)` → `AES-256-GCM`；每行自带 salt/iv，篡改或口令错误一律解密失败（GCM 认证），不会返回错误明文。关闭加密时退回明文并明确告知。
- **钥匙串**：启用"记住主口令"才写入系统钥匙串（Windows Credential Manager / macOS Keychain），不落地到任何文件；解锁时用存的校验值验证，失败即不进入解锁态。
- **CSP / 前端**：`default-src 'self'`、`object-src 'none'`、`base-uri 'self'`、`frame-src 'none'`、`form-action 'none'`；`freezePrototype` 关闭原型污染入口；不加载远程脚本、不做远程更新。
- **Tauri 能力**：capabilities 只授予自家窗口的窗口几何/置顶和文件选择对话框；未使用的 opener / notification 插件不注册、不授权。
- **自定义协议**：`petasset://` 只读（GET/HEAD）、路径 `canonicalize` 后必须仍在素材根目录内（防 `..` 与符号链接逃逸）、仅 webm/webp/png/jpg/json、单文件 64 MB 上限、`X-Content-Type-Options: nosniff`。
- **进程执行**：Dock 与启动器只接受 `.lnk/.url/.exe/.app`；路径 `canonicalize` 后必须落在配置目录内；子进程用参数数组传递（无 shell 拼接），并带 `CREATE_NO_WINDOW`。
- **文件导入**：壁纸按**文件头魔数**校验 png/jpg/webp，不信任扩展名；单文件 20 MB 上限；只拷进应用数据目录，不原地引用。
- **写入安全**：全部走「临时文件 + rename」原子写；文档编辑带 SHA-256 CAS，外部改动不会被静默覆盖。
- **路径安全**：文档名、密钥文档名经过保留字/路径分隔符清洗（含 Windows `CON`/`NUL` 等设备名拒绝），无法写出数据目录。
- **仓库卫生**：不提交任何密钥、证书、真实数据；`dev-data/` 为合成数据并被忽略；日志与 `.env*` 被忽略。

- **AI 助手**：API Key 只存系统钥匙串；请求从 Rust 侧直连用户配置的 base_url（无中转）；模型只能通过白名单工具改数据，写入与手改共用同一套原子写并登记撤销快照；只读模式在**后端**拒绝写工具（不依赖提示词）；凭据不提供给模型。

## 已知边界（不是漏洞，但你需要知道）

- **不加密时凭据就是明文**：`凭据.md` 是普通 Markdown。请在"设置 → 安全"里启用主口令加密，并让该文件远离云同步目录。
- **忘记主口令无法恢复**：没有恢复密钥，这是设计取舍。
- **主口令存钥匙串 = 以当前登录用户身份可解**：能运行你账户下程序的攻击者能取到它（这是钥匙串的通用语义）。更严格的做法是每次启动手输。
- **Markdown 里的链接点击会在系统浏览器打开**：链接来自你自己的数据文件，应用不校验域名。
- **桌面级窗口会置顶**：Dock / 桌宠 / 卡片使用 always-on-top，全屏应用可能被它们遮挡，这是功能而非缺陷。
- **素材协议只做根目录约束**：素材目录里放什么文件由你决定；不要把不可信目录直接指定为素材根。
- 应用**没有自动更新**：升级靠你自己下载新安装包，这消除了更新链路的攻击面。
- **AI 的信任边界**：启用远端模型后，对话内容与工具返回的文本会发给你配置的服务商。工作台文件若含他人可写的内容（同步盘、共享目录），理论上可夹带「提示注入」诱导模型做别的操作；缓解手段是：工具集固定且最小、凭据不暴露、每笔写入可撤销并留痕、只读模式后端强制。请把笔记目录当作你信任的输入。
- **AI 的整篇覆盖型工具**（如 keys_write）会覆盖同名文件；手改与 AI 同时改同一文件时，撤销会因哈希不符被拒绝，此时以文件现状为准。
