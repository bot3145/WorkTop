## 推荐优先级

1. **先做 D**（16s 信息流）——可用 MoneyPrinterTurbo 技能一键成片试跑，成本最低、最快验证。
2. **主推 A**（33s 品牌片）——官网与 Release 页门面，建议 OpenMontage/openshot 精修。
3. **B / E 按渠道跟进**，C 需要托托动效素材可后置，F 直接挂 README。

## 快速使用

- 旁白音频已按**分镜逐句**拆分（`audio/A/A01.mp3…`），可直接对轨剪辑；完整版在各目录 `完整旁白-X.mp3`。
- 改旁白词：编辑 `gen_tts.py` 中对应文案 → `python gen_tts.py` 重跑（全量重生成，约 1 分钟）。
- 高质量配音：启动 VoiceStudio（`http://127.0.0.1:3900/mcp/`）后换更自然音色或克隆音色，文案不变。
