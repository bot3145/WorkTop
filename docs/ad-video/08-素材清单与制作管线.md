## 四、成片规格建议

| 项 | 规格 |
|---|---|
| 主版本 | 1920×1080 / 30fps / H.264 / 高码率（官网用） |
| 信息流版本 | 1080×1920 竖版（创意 D 另排竖版分镜：卡片纵向堆叠） |
| 片头贴片 | 6s cut（创意 D 前 6s 再剪） |
| 封面帧 | hero-全景 + 主口号大字（A 用"把桌面还给你"，D 用"3MB"） |
| 字幕 | 全程硬字幕，安全区下沿 12%，与 UI 同风格圆角底条 |
| 第三方图标 | QQ/微信/WPS 等特写镜头虚化或打码（版权红线，见 00 文档） |

## 五、版权红线（重申）

1. BGM/音效只用 Pixabay / YouTube Audio Library / Freesound(CC0) 等可商用免费源
2. 截图内第三方应用 logo 特写需处理；演示数据尽量用假数据
3. 截图功能口径写"WorkTop 原生截图"，只展示已实现的选区、矩形/箭头/画笔、复制与保存
4. 密钥/凭据界面演示必须用空数据或假数据（本机截图已有"还没有密钥文档"，安全）
