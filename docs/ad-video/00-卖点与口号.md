# WorkTop 卖点库 · 口号 · 人群

> 广告文案的事实底座。所有创意的旁白与字幕均从这里取材，不得虚构。

## 核心定位

**本地优先的个人工作台 · Local-first personal workbench**
待办、导航、资产、凭据、速记、密钥文档——全部 Markdown 明文存在自己电脑上，外面包一层类 macOS 桌面壳与原创吉祥物。没有账号、没有云同步、不上传任何数据。

## 卖点库（按说服力排序）

| # | 卖点 | 事实依据 | 一句话文案 |
|---|---|---|---|
| 1 | 数据自主 | 数据 = `待办.md` 等明文，Obsidian/VS Code 可直接共编 | 你的数据，从头到尾只在你电脑里 |
| 2 | 桌面卡片 ×9 | 时钟/日历/待办/便签/应用/导航/资产/密钥/AI快问，独立透明窗口，拖动缩放磁吸对齐 | 常用的一切，摆回桌面 |
| 3 | 桌面级 Dock | 扫描开始菜单自动出图标；点击直启；再点最小化/恢复；拖动排序；可替代任务栏 | 更懂 Windows 的 Dock |
| 4 | 吉祥物托托 | 纯 CSS 原创，可拖动、贴边折叠、待办角标，点击扇形菜单（待办/速记/AI/设置/截图） | 不领工资的桌面同事 |
| 5 | AI 快问（BYOK） | 接 OpenAI 兼容接口，22 个工具直接读写待办/导航/速记/资产/记忆，**每次写入可撤销**，密钥只进系统钥匙串 | 帮你干活，不抢方向盘 |
| 6 | 原生截图 | F1 即截，选区移动/缩放，矩形/箭头/画笔标注，复制/保存 PNG | F1，一秒截 |
| 7 | 轻量 | NSIS 安装包约 3MB；Lite 版零依赖 Node ≥18 即跑 | 轻，但能打 |
| 8 | 凭据保险库 | scrypt + AES-256-GCM 主口令加密，文件哈希 CAS 防冲突 | 密钥锁进本地保险库 |
| 9 | 双版本同数据 | APP 与 Lite（localhost:8791）共享同一套 Markdown 格式，一键迁移数据目录 | 两个版本，一份数据 |
| 10 | 干净 | 不写注册表、无开机自启、无遥测；不配 Key 时完全离线 | 零账号，零云，零遥测 |
| 11 | 开源 | MIT；卡片/面板/Dock 独立组件可定制（业务看板卡、企业导航壳、私有部署） | 开源是邀请函，定制是回信 |

## 主口号（按场景选用）

- **品牌向**：WorkTop，把桌面还给你。
- **隐私向**：数据是我的。／ 你的数据，从头到尾都只在你电脑里。
- **功能向**：轻，但能打。／ AI 坐在桌面上。
- **社区向**：开源是邀请函，定制是回信。

## 视觉基调（来自现有截图）

- 主色：**鼠尾草绿 × 白卡片**，圆角、柔和阴影、透明浮层
- 壁纸：自然风光（雪山湖景），卡片浮于其上 = "桌面回归桌面"的视觉母题
- 呈现元素：时钟/日历/待办/AI快问/密钥/便签卡片、左右两处 Dock、右下角托托
- 字体建议：字幕用与 UI 一致的圆润无衬线（思源黑体 / HarmonyOS Sans）
